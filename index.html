Featured Projects

Four projects, each with its code on GitHub and a live demo.

Energy & Technology

NammaElectricity

A context-aware electricity platform for urban households. It estimates bills using tariff and subsidy rules (including Gruha Jyothi), analyses consumption and peak usage, and estimates how much energy individual appliances use. It then suggests ways to cut consumption, and uses reported local outages to give reliability insights and backup power planning.

  • React
  • TypeScript
  • FastAPI
  • PostgreSQL
  • Pandas

Agriculture & AI

KhetiSahayak

An AI-powered farming companion that brings guidance and tools into one app, so farmers do not have to rely on scattered sources. It includes a chatbot for agricultural questions powered by the NVIDIA API, a crop image analysis feature for exploring crop issues, weather information, and crop cost tools.

Home Services & Technology

FIXIO

A web-based home services marketplace that connects customers with service professionals. Users can browse the services on offer and book them through a responsive interface. It is built as a full-stack project, with an HTML, CSS and JavaScript frontend and a Node.js and Express backend using MongoDB.

Healthcare & Technology

Medix

An NLP-based disease prediction system. You describe your symptoms in plain text, the text is cleaned and converted into TF-IDF features, and a trained model (Naive Bayes and Logistic Regression were compared) predicts the probable condition. Built on the Symptom2Disease dataset from Kaggle with a Streamlit interface. For learning only, not for medical diagnosis.

  • Python
  • Scikit-learn
  • NLTK
  • TF-IDF
  • Streamlit
